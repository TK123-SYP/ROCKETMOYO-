
# ⚾ ROCKETMOYO
### Baseball Performance Analytics and Player Development System

## 1. Introduction
ROCKETMOYO is a baseball analytics application designed to help baseball players and coaches identify potential batting weaknesses, monitor player performance and make informed training decisions.

The project focuses on making baseball performance analysis more accessible to players and coaches in Zimbabwe.

## 2. Problem Statement
Many developing baseball players lack access to affordable performance analysis tools. This makes it difficult to identify batting weaknesses, monitor improvement and plan targeted training.

ROCKETMOYO aims to address this challenge through accessible, statistics-based analysis.

## 3. Main Features
- Baseball statistics dashboard.
- Manual player performance analysis.
- Batting average and strikeout rate calculations.
- Weakness detection indicators.
- Training recommendations.
- Individual player profiles.
- Persistent match history.
- Performance improvement tracking.
- Player performance reports.
- Downloadable PDF reports.

## 4. Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- Pybaseball
- ReportLab

## 5. Installation

Clone or download the project.

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```

## 6. Target Users
- Baseball players.
- Baseball coaches.
- School baseball teams.
- Developing baseball clubs in Zimbabwe.

## 7. Project Objective
To make baseball performance analysis more accessible and help players understand their performance, identify possible weaknesses and improve through targeted training.
